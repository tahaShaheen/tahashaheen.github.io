I made a video explaining the features of [Robo-Chotu](/projects/robochotu_fyp). Communication in the robot is done through the Google [Dialogflow](https://cloud.google.com/dialogflow) API and a custom chatbot. The skeleton detection uses CMU Perceptual Computing Lab's [OpenPose](https://github.com/CMU-Perceptual-Computing-Lab/openpose).
