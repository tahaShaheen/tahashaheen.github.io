# Taha Shaheen

Source for [Taha Shaheen's personal academic website](https://tahashaheen.github.io/).

The site presents research, publications, projects, presentations, and extracurricular work. It is built with [Jekyll](https://jekyllrb.com/) and deployed with GitHub Pages.

## Content

- `_pages/` contains site pages, including the résumé and publications page.
- `_projects/` contains research and project write-ups.
- `_extra_curriculars/` contains cultural-exchange and other extracurricular content.
- `_bibliography/papers.bib` holds publication records and cited references.
- `assets/` contains images, video, PDFs, and résumé data.

## Local development

The repository includes a Docker configuration for serving the site locally with Jekyll and live reload.
